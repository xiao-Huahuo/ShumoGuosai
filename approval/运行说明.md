# 支撑材料运行说明

先在本目录根位置执行 `python src/prepare_support_data.py` 恢复并校验缓存，再运行各问程序。请按各问依赖清单建立独立Python环境，第一、二问及第四问冻结环境的版本不同。五份已完成Excel可直接从 `outputs/final/` 打开。

## 主程序

第一问读取原始附件，完整计算命令为 `python src/q1/run.py --no-plots`，依赖见 `src/q1/requirements.txt`。Excel导出代码另在 `src/q1/export_submission.mjs`，需要原程序所用的Node依赖 `@oai/artifact-tool`，四份导出所需CSV已保留。

第二问保留了经封存校验的完整准备库。应先将准备库复用至新目录，再求解，避免覆盖已经作为后续问题输入的正式结果：

```sh
python src/q2/dispatch.py reuse-prepared --source-run outputs/q2/dispatch_runs/20260912_tail_reserve_final --run-dir outputs/reproduce/q2
python src/q2/dispatch.py run --run-dir outputs/reproduce/q2 --rescue-seconds 900
```

依赖见 `src/q2/requirements.txt`，该复用入口会继承已保存的精度配置。需要从附件重新训练预测时使用 `prepare` 子命令，输出指定全新目录。

第三问实际运行源码在 `outputs/q3/raw/full_priority_rescue_7h_20260912/runtime/`。从该runtime目录运行 `python -m src.q3.full_run --help` 查看入口，以 `Q3_WORKSPACE_ROOT` 指定本材料根目录。必须把 `--q2-run` 指向本材料中的 `outputs/q2/dispatch_runs/20260911_224501/`，输出使用新目录；精度、四节点和限时接受参数参照保留的 `execution.json` 与正式验收记录，不能只运行默认参数便声称复现原结果。

第四问4-2采用 `docs/4/rescue_lp/frozen_source_v2/`，4-3采用 `frozen_source_v3/`。从对应冻结源码根目录执行 `python -m src.q4.run q42 --output <新目录>` 或 `q43`，并将 `Q4_WORKSPACE_ROOT` 和 `Q3_WORKSPACE_ROOT` 设为本材料根目录。原始附件、Q2预测选择数据和Q4价格缓存均已保留。
