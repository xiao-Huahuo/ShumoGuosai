# 支撑材料

代码、原始附件、五份最终Excel、AI使用报告和参考文献直接保存在本目录。计算缓存合并存入 `计算缓存.dat.xz`，这是程序数据文件，外层交付格式为ZIP。

## 运行前准备

在本目录打开终端，先执行：

```sh
python src/prepare_support_data.py
```

此步骤只用Python标准库，将缓存恢复到原相对路径，并逐份核对SHA-256。已存在且内容一致的文件会跳过，不覆盖内容不同的文件。数据恢复后，按[运行说明](运行说明.md)配置对应依赖和运行程序。

第二问敏感性实验的四份中间数组已移出，实际验证过能由现有程序精确重建。仅在运行该实验前执行：

```sh
python -c "from src.sensitivity.q2 import prepare; prepare()"
```

此命令需要第二问依赖环境，不重新求解优化模型。重建的四组数组、每组11个字段已与原数据逐元素精确比较一致。
