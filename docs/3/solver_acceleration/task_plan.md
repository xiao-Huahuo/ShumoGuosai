## 错误与修复

- 首次三节点 capture 因 `dict.update()` 混用关键字参数与字符串键产生 SyntaxError，未写入任何 fixture；已改为单个字典参数，并在重试前执行语法检查。

- 发现 highspy 1.15 的低层 `setCallback/startCallback` 路径在真实 40/120 秒矩阵上没有产生周期事件；轨迹只有求解结束后的最终保存。若把内部 gap 设 0 且生产时间设极大，将无法按原 replay 3% 及时停止，属于 P0 迁移阻断。已改用官方高层 `Highs.cbMip*` 事件接口，正在实际验证 30 秒 durable callback 与可靠证书中断；通过前绝不迁移。
