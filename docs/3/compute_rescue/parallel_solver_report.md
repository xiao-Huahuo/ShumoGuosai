## 已完成的修复

原路径直接使用SciPy内置HiGHS 1.8；给它设置threads=4后，本次实测主MIP仍主要使用1核。官方[HiGHS 1.15.1发布说明](https://github.com/ERGO-Code/HiGHS/releases/tag/v1.15.1)明确该系列首次提供并行MIP。本次单独固定highspy==1.15.1，保留Q2固定依赖，将fast_solver接入新版并设置真实4线程与parallel=on。原build_base/build_matrix/linear_seed/seed_vector函数源文与升级前完全一致。

full_run新增并逐层传递solver-threads；正式以2个历史标定worker、4个主求解线程运行，额度检查为8≤本机10核。历史辅助任务自身仍1线程，和主节点不同时运行。fast_solver适配新版回调数组；候选先检查有限值与变量界，拒绝无效向量后再做矩阵乘法，消除原候选运算警告。原反馈费用、矩阵、整数、投影与界检查全部保留。
