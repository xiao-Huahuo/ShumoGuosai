## 等价性依据

原反馈在同一购电g、放电上限rp和净负荷下，充电时下一SOC为min(Emax,E+η min(cp,g−n))；放电时下一SOC为max(Emin,E−min(rp,n−g)/η)。两种映射都随当前SOC单调不减。提高cp到设备上限使SOC逐时不减、紧急购电不增；其他正常购电和调整费只依赖g，非负终端系数的残值也不恶化，故自由优化可以固定cp为设备上限。

紧凑矩阵保留精确放电最小值，充电允许低于原饱和反馈。将任一整数可行策略用原replay执行，按上述单调归纳可得原执行SOC不低于矩阵轨迹、紧急量不高于矩阵轨迹，因此原目标不高于矩阵目标。反过来，原始饱和反馈轨迹可嵌入矩阵。两方向共同保证最优值相等；不声称任一中间轨迹都逐值相同。

自由g可裁剪到max(max_s n_s,0)+CAP：超过此值时所有场景都有至少CAP剩余，裁剪保持充放电和SOC，只减少弃电；原正常费用及非对称调整费用都随g严格递增。固定策略保留原上界。对已知净负荷前缀逐点有序的场景，原反馈满足SOC反序、紧急量同序、弃电反序，加入这些有效约束仍包含原可行策略集合，并加强下界。

实现持续独立复核矩阵可行性、整数性、原反馈投影及原目标，不将求解器内部放松充电轨迹输出为真实执行。正终端、非对称调整、固定策略及原模型最优值比较均有实际有界测试。
