# 并行实现依据

- 资源检测：macOS arm64，可见10物理/逻辑核，16GiB统一内存；当前空闲内存未由检测器确认，不假定全部可用。
- PySCIPOpt 6.2.1本机构建可用solveConcurrent。实际120二元变量/30约束小探针输出“Using 2 threads for concurrent solve”和scip-1/scip-2两个求解器，0.2秒预算正常返回。
- 原代码make_model硬编码parallel/maxnthreads=1，且调用optimize；只改maxnthreads不会启动concurrent。
- 原全年实验40条独立SOC链顺序执行；可以进程并行。FIV两分支共享输入与初态，互不改变主轨迹。
- FD每个历史日的E/E+100两个辅助问题可按历史日并行；必须先在父进程筛选完整实现历史再提交。

- 实测默认选择4进程×1SCIP线程：四个8秒预算问题33.655→9.064秒（含启动），3.713倍；目标/下界/gap/grid逐值一致。四worker峰值最大614.2MiB。
- 原生2/4线程8秒短测端到端9.79—10.18秒，高于单线程8.42秒，gap未改进，因此默认不启用。
- FD复用热池1.878→0.553秒（3.394倍），系数相同。合并32测试15.060秒通过；未运行全量。
