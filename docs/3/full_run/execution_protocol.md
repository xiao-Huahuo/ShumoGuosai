## 保存与恢复

- 求解前保存已知可行策略；SCIP事件允许时约每10秒保存候选策略和有效下界，预求解阶段保留已知可行初值；每120秒切片完整落盘一次。不是严格每10秒实时操作系统快照。
- 未达3%时继续下一片。同一个存活进程继续原SCIP求解；进程崩溃后使用匹配输入摘要的策略/下界重建模型，不声称完整恢复分支搜索树。
- 每个00/06/12/18节点保留独立求解快照；每个6小时真实执行块保存CSV。已完成节点重启后先物理/目标/摘要核验，再直接复用。
- 每日CSV、节点审计、信息记录先写出，再原子提交日收据。所有JSON/CSV采用UTF-8、临时文件、fsync和原子替换；最终Excel也在回读验证后同步落盘。
- 历史FD按单个历史日持久缓存并校验摘要。抽样任务按节点、FIV分支和已完成任务分别保存；完整任务收据校验结果文件哈希。
- 单写入者锁防重复启动。监督进程对异常退出自动从检查点重启，连续3次异常后停止重复失败并在进度页显示原因。长时间无工作文件更新（至少600秒/5个切片）触发卡死恢复。
- worker独占进程组；异常退出时回收其池进程。监督消失时worker停止，避免留下无人管理的后台计算。机器重启后仍需重新执行启动命令，随后自动读检查点；未设置开机自启。
