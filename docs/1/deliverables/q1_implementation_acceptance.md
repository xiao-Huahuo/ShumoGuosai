## 结果合理性与偏离预期的发现

主模型仍满足全天能量恒等式、SOC范围、充放互斥、功率限制与日周期，全部光伏净富余均被吸收；加权充电价格低于加权放电价格。保留原有敏感性实算发现：降低效率后充电量增加、放电量下降；负荷增加没有提高放电功率边际价值，光伏增加也没有造成弃光或储能空间价值上升。因此论文中的这些方向只保留为检验问题，不能写成已证实趋势。

原MILP两侧有限差分不能同时匹配固定模式影子价的项目为25项，原MILP非光滑或单侧项目也是25项。它们不意味着主模型求解错误，而是限制了固定模式μ、λ的经济解释。所测步长匹配也只支持该步长附近的解释，不是一般可微性证明。

在1、10、100三个放宽步长下，主方案提高储能上限的单位日价值约0.655045556元/(kWh·日)，降低储能下限约0.659378889元/(kWh·日)，提高充电功率约0.056466667元/(kW·日)，提高放电功率为0。前三者均数值稳定，但缺少设备投资成本，未宣称经济上值得扩容。下限降低是诊断实验，正式结果仍遵守1200kWh。

## 假设与决断审查

没有新增电池衰减费用、售电机制、二级目标或擅自给定经济显著性门槛。PV-only及No-ESS共同增加富余光伏时G=0的来源约束，以保证字面来源语义及基准嵌套；对非负电价不提高无储能最优费用。eta_d默认等于eta_c仅兼容原调用，函数接受独立效率并通过非对称解析例验证。

所有新增合成算例仅存在于测试中，正式CSV全部来自题目附件。golden只固定原始输入SHA与目标值，不强制不唯一的逐时调度或空闲模式。
