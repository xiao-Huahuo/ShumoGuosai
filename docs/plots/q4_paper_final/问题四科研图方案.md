# 问题四科研图方案

设计决定：使用用户ThemeDisplayer中的Blue Lotus五色（#19309A、#4B69EF、#7E96FE、#B6D8F7、#FFB967），搭配月白深蓝的#FFFEF0、#CDBFE2、#002254。以蓝—淡紫渐变为主，杏橙仅区分紧急风险或不利费用变化。中文采用本机TeX Live 2026的FandolSong-Regular，拉丁文字用Latin Modern Roman，数学使用Computer Modern，不使用微软雅黑。图的设计服务于真实统计含义，不靠平滑或删除极值提高观感。

数据范围：问题4-2正式v2、问题4-3正式v3，2025-02-01至12-31共同334日，每日144时段；两条轨迹均从6000kWh开始，各自连续传递SOC。正式1670节点全部Optimal。只读后处理，不改正式结果，不新增求解。

正文优先7-1、7-3、7-5；7-2用于电价预测说明，7-4用于模型中的调用/弃电语义说明，7-6放敏感性分析。每张配图注与简短图后分析，统一PNG400dpi与中文转曲SVG，源表和重绘代码入ZIP。

比较边界：4-2和4-3还存在前瞻长度、更新频次和连续库存轨迹差异，所以费用差是两套完整策略在共同日期上的实际表现，不是FIV/OUV，也不是单独价格模型的价值。日度费用差受库存继承影响，全文需同时列示两条最终SOC。跨日分位带描述样本波动，不是置信区间。极坐标小时聚合仅用于统计展示，控制器仍为10分钟。

验收：逐项核对模型机制/单位/已知信息边界、两条真实能量平衡和SOC递推、费用差加和、密度总计48096、流图源汇守恒与未调用独立、敏感性真实基准；逐图目视中文与数学字体、标注和图例；浏览器验证图集后做ZIP CRC/SHA校验。
