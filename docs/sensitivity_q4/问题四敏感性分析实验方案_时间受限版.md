# 问题四敏感性分析实验方案（时间受限版）

## 1. 实验目标

问题四在问题二、问题三的基础上进一步引入实时波动电价，并同时考虑：

1. 未来实时电价不确定性；
2. 净负荷不确定性；
3. 电价与净负荷之间的联合不确定性；
4. 储能跨时段耦合；
5. Wasserstein 分布鲁棒优化。

因此，问题四的敏感性分析主要检验模型自行引入的“不确定性描述参数”和“鲁棒优化参数”是否稳定，而不修改题目给定的电价倍率、储能容量、效率等物理条件。

实验主要回答以下问题：

1. Wasserstein 鲁棒半径发生合理变化后，真实运行成本和紧急购电风险是否稳定；
2. 价格与净负荷在联合距离中的相对权重变化后，主要结论是否改变；
3. 历史残差窗口变化后，最终调度结果是否稳定；
4. 场景规模增加后，经济结果是否已经基本收敛；
5. 问题 4-2 中的参数稳定性是否能够迁移到问题 4-3 的四时点滚动调度。

本实验不用于在测试数据上寻找“最优参数”，而用于证明正式结果不存在明显参数脆弱性。

结合正式模型，选择以下四类参数：

|---|---:|---:|---|
| Wasserstein 半径 ρ | ρ* | 0.75ρ* / ρ* / 1.25ρ* | 必做 |
| 联合距离权重 (ω_N, ω_p) | (0.5, 0.5) | (0.7,0.3) / (0.5,0.5) / (0.3,0.7) | 必做 |
| 历史残差窗口 W | 当前正式值 | 56 / 84 / 112 日 | 可选 |

其中：

- Wasserstein 半径直接控制分布鲁棒程度，是问题四最高优先级的敏感参数；
- 联合距离权重直接决定价格误差和净负荷误差在联合场景构造中的相对作用，与“价格—源荷联合不确定性”这一核心模型设计直接相关；
- 历史残差窗口用于验证历史分布估计是否依赖某个特定窗口长度；
- 场景规模主要用于验证数值稳定性与计算效率之间的关系。

# 3. 不进行扰动的参数

以下参数属于题目给定条件，不进行敏感性修改：

- 调整增购部分按交易价格的 1.5 倍支付；

- 储能最大容量；

- 最大充放电功率；
- 充放电效率 90%；
- 附件 4 中的真实实时电价。

同时不在本阶段重新进行 Elastic Net 大规模超参数搜索。

价格预测模型已经通过严格时间顺序的历史训练与验证确定，本次敏感性分析主要针对最终随机优化与鲁棒调度层。

- 真实回放方式。

6. Q4-S1：Wasserstein 半径敏感性
6.1 实验目的

Wasserstein 半径 ρ 控制概率模糊集大小。

较小的 ρ 更接近经验分布优化，较大的 ρ 允许更大的概率质量迁移，使优化模型更加关注有限样本造成的分布估计误差。

这是问题四最核心的敏感参数。

6.2 参数设置

定义：

rho_test = k_rho * rho_base

测试：

设置	k_rho
弱鲁棒	0.75
基准	1.00
强鲁棒	1.25

其余内容全部冻结。

特别保持：

同一历史联合残差池；
同一联合场景；
同一经验场景概率；
同一初始 SOC；
同一预测结果；
同一求解器设置。

只改变 Wasserstein 半径。

6.4 Q4-3 额外指标

6.5 结果判断

主要判断：

ρ 增大后模型是否更加稳健；
紧急购电风险是否下降；
普通购电成本是否适度增加；

Q4-3 调整行为是否发生明显异常；

该实验不用于证明“ρ 越大越好”。

真正需要证明的是：

正式调度结果在合理 Wasserstein 半径范围内具有稳定性。

7. Q4-S2：价格—净负荷联合距离权重敏感性
7.1 实验目的

正式模型采用标准化价格—净负荷联合轨迹距离。

基准为：

omega_p = 0.5

该实验用于回答：

模型结果是否依赖“净负荷和价格恰好各占 50% 权重”。

7.2 参数设置

测试：

设置	ω_N	ω_p
净负荷偏重	0.7	0.3
基准	0.5	0.5
价格偏重	0.3	0.7

始终保证：

omega_N + omega_p = 1
7.3 实现要求

该实验不能只改变优化目标中的某个系数。

因为 ω_N 与 ω_p 直接参与联合轨迹距离计算，因此每个配置必须重新执行：

联合轨迹距离计算
→ 尾部保持 k-medoids 场景缩减
→ 场景概率重新计算
→ Wasserstein 距离构造
→ DRO 求解
→ 真实数据回放

否则不能构成真正的联合距离权重敏感性实验。

17. 论文结果解释原则

敏感性分析不要求参数改变以后所有数值完全不变。

真正需要验证的是：

总成本没有出现异常的大幅波动；
紧急购电风险没有突然失控；
SOC 没有出现明显异常；
Q4-3 调整行为没有发生异常跳变；
模型主要经济结论没有发生反转。

如果结果总体稳定，可写：

对 Wasserstein 鲁棒半径、价格—净负荷联合距离权重等核心参数进行合理范围扰动后，模型真实结算成本、紧急购电风险及储能运行状态均未出现明显异常变化，主要经济结论保持一致，表明波动电价下的联合鲁棒调度结果并非依赖某一精确参数取值，具有较好的参数稳健性。

如果随着 ρ 增大表现为普通购电略有增加、紧急购电风险降低，可写：

随着 Wasserstein 半径增大，模型逐渐采用更加稳健的购电与储能配置，以一定的常规购电成本为代价降低高价格状态下的紧急购电风险，体现了经济性与鲁棒性之间的合理权衡。

如果联合距离权重变化后结果仍然稳定，可写：

当价格误差和净负荷误差在联合距离中的相对权重发生合理变化时，模型主要经济结果和风险指标保持稳定，说明联合场景建模的有效性并非由特定的等权参数设置偶然产生。
