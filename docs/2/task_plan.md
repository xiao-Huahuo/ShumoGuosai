- 用户明确确认：严格排除等于 0:00 的点，使用 `timestamp < origin`。
- 数值方法、滞后上限、检验口径和图表聚合在运行配置与报告中披露；不把软件设置当成题设参数，不设未经论证的周期强弱硬门槛。
- 不删除或平滑统计极值；明显物理错误和结构错误保留核验记录并阻止诊断，不能静默填补。
- 结果表格 CSV，图 PNG/SVG，原始 XLSX 只读取；UTF-8 无 BOM，输出路径英文。

## 已遇问题

- 当前工作区无 `.git`，不能提供 Git diff；仅增改 Q2 及要求同步的根文档。
- 根 TASK_STATE 是上次 Q1 过期过程记录，保留其内容，最终另加本轮 Q2 状态。
- 系统 Python 无科学计算依赖；使用 uv 隔离环境固定版本，不改全局环境。
- 预检发现既有源码文件为 model.py，没有 data.py/io.py；改按实际文件读取。
- 初次测试发现 pandas 的 Series.equals 会因日期精度 dtype 不同拒绝实际相等的日期；改为逐元素时间值比较，保留真实跨午夜与计费手算测试复验。
- 初次PACF预检受BLAS线程调度开销影响；限定数值线程数1后，完整两scope诊断约24秒，未缩减2016阶要求。
- 1月光伏在周频附近存在很小局部峰，不能仅据此宣称独立周效应；候选优先级还要求去日曲线后周相关强于日相关，不以临时强弱阈值强行选型。
- 首次全流程发现追溯程序遗漏总标题2.1（各子节已映射），发布被阻止；补总标题映射。图字体不含上标负号，改为等价的ASCII斜线单位，并将缺字警告升级为绘图失败。
- 图形目视发现月份图例覆盖峰值；将月份/星期图例移至图外，同时给相关图加入准确的144/1008/2016轴标。
- 新增发布失败测试首次因macOS `/var`与`/private/var`别名比较失败；断言改用双方resolve。审查同时补充切换失败时移除暂存指针，测试失败后重试也必须成功。
- 浏览器390px实测发现“后续评价数值状态”表没有横向滚动容器，导致页面宽863px；修复为表内滚动、长链接换行，空指标显示“未计算”而非None。
- 星期图发现真实低负荷在周五/周六，与通常周末直觉不一致；独立核对原始日期与星期，保留原值，在结果报告添加七日均值及偏离预期说明。
