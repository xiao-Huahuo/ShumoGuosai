# 补算MILP线性编码的等价性与真实验收

## 适用范围与决策依据

用户已授权自主全量计算、验收和修复。2026-09-12，固定K=1实验的2025-04-13在SCIP原120秒及补充900秒后仍未达到1%精度。原生指示约束模型保持主路径；仅原预算整日候选全部受限后的补算采用HiGHS 1.8.0线性MILP。方案2.7.6允许不支持原生指示约束的平台使用从物理边界推导的激活常数。本实现遵守该限制，未改变预测、场景、目标、响应策略或精度门槛；原失败记录不改写为通过。

适用于单段主策略，不将此推导擅自用于三段SOC策略。三段诊断继续使用原生指示约束，并新增完整策略CSV、逐日期原子收据及重复回放校验。

## 变量与激活常数

记当前净缺口为x=n-g，充/放电上限为cp/rp，C=D=5000/6，a=ηd(Eprev−Emin)，b=(Emax−Eprev)/ηc。沿用方案给出的购电冗余上界G=max(max_s n_s,0)+C。响应变量c,r,q,w均非负，且c/r≤C、q≤max(n,0)、w≤max(G−n,0)、Emin≤Eprev≤Emax。

每个响应分支用一个二元选择变量y激活下列不等式。M均为括号左式在已知边界下的有效上界，未取任意大数：

| 被激活的最小项 | 编码 | 由物理边界得到的M |
|---|---|---|
| 放电上限 | rp−r≤M(1−y) | C |
| 当前缺口 | n−g−r≤M(1−y) | max(n,0) |
| 可用电量 | a−r≤M(1−y) | ηd(Emax−Emin)；首时段为已知a |
| 充电上限 | cp−c≤M(1−y) | C |
| 当前剩余 | g−n−c≤M(1−y) | max(G−n,0) |
| 剩余容量 | b−c≤M(1−y) | (Emax−Emin)/ηc；首时段为已知b |

此外保持r≤rp、r≤a、c≤cp、c≤b。方向变量z约束c≤C(1−z)、w≤Wmax(1−z)、r≤Cz、q≤Qmax z；三个放电选择变量之和为z，三个充电选择变量之和为1−z。

若z=1，c=w=0，能量平衡推出r+q=n−g≥0，同时r≤n−g。三个放电最小项中恰有一个取等，结合所有上界即r=min(rp,n−g,a)。若z=0，同理由r=q=0及平衡得到c+w=g−n≥0，最终c=min(cp,g−n,b)。缺口为零时两种z都只能给出零充放电及零紧急/未利用电量。SOC递推保持原式。因此线性编码与原单段min/max反馈策略的可行解和费用逐项对应，场景响应没有被放宽为自由recourse。

## 可行初值与全局证书

L-BFGS-B给出的共享策略先由原始逐步映射生成完整可行向量。固定分支LP在30秒内迭代到费用不再改善，并设1000轮数值保护上限；固定分支的最优值绝不用于全局下界。每轮重建真实反馈响应，最后逐行检查全部线性约束。正式MIP恢复响应分支变量的原边界，未固定初值的分支；充电上限的支配性预处理见下节。原10轮上限在4月16日实例中尚未收敛，因此取消提前截断，30秒预算保持不变。

## 单段充电上限的支配性预处理

固定同一组日前购电g和放电上限rp，比较不同充电上限cp。令x=n−g。由原始反馈响应和SOC递推直接得到：

- x≥0时，下一时段SOC为max(Emin, E−min(rp,x)/ηd)，对当前SOC单调不减，与cp无关；紧急购电max(x−min(rp,ηd(E−Emin)),0)对SOC单调不增。
- x<0时，下一时段SOC为min(Emax, E+ηc min(cp,−x))，对SOC和cp均单调不减；紧急购电为零。

因此，将任意单段策略的所有cp提高至题设上限C，逐时归纳可得每条净负荷路径的SOC不减、紧急购电不增，所有容量、功率、互斥和负荷优先约束仍满足。g保持不变，目标仅包括计划购电与正权重的紧急购电费用，故费用不会增加。这一论证逐路径成立，不需要知道实际未来负荷。

原模型中cp=C的策略是其可行子集；同时，任何原可行策略都可转为该子集中的费用不高于原策略的可行策略。所以两个优化问题的最优值相等。预处理固定cp=C，消去被支配的选择，提供的MIP全局下界仍是原优化问题最优值的有效下界。这不是宣称所有原策略在预处理后仍逐一保留。

适用条件均来自现有单段目标与约束：原文2.8.1明确充放电响应上限不直接产生费用，目标只含计划与紧急购电；没有吞吐量费用、末端SOC等式或分段SOC参数切换。不得将该证明外推到三段SOC诊断，或将cp=C覆盖用户指定的固定策略。实现仅在fixed_policy为空时启用；固定策略回放保留原cp。原120秒SCIP主路径及方案参数保持不变。

初值准备共用原30秒预算：先把候选cp提高到C，在原cp允许范围内做固定响应分支的局部LP改善；再将改善后的cp提高到C，在支配性预处理后的边界内继续改善。两阶段都只给可行上界，均用原始respond/replay重建响应；最终完整向量按正式MILP的全部边界和约束逐行检查。第一阶段释放的只是临时初值问题的cp边界，没有释放正式MIP的边界或把局部LP值当全局下界。

## 原反馈分支的四条有效约束（4月24日瓶颈）

令lr0、lr1、lr2分别选择放电上限、当前缺口、可用电量三项，lc0、lc1、lc2选择充电上限、当前剩余、容量空间三项。其和分别为z和1−z。记Qmax=max(n,0)、Wmax=max(Gmax−n,0)、ΔE=Emax−Emin。补算的线性模型增加：

| 有效约束 | 原整数反馈为什么必然满足 |
|---|---|
| q≤Qmax(lr0+lr2) | lr1=1时r=n−g，能量平衡给q=0；充电方向也有q=0；其余放电分支沿用物理上界Qmax |
| w≤Wmax(lc0+lc2) | lc1=1时c=g−n，能量平衡给w=0；放电方向也有w=0；其余充电分支沿用物理上界Wmax |
| Epost+ΔE·lr2≤Emax | lr2=1时r=ηd(Eprev−Emin)，且c=0，递推给Epost=Emin；lr2=0时为原SOC上界 |
| −Epost+ΔE·lc2≤−Emin | lc2=1时c=(Emax−Eprev)/ηc，且r=0，递推给Epost=Emax；lc2=0时为原SOC下界 |

四条不等式对原模型的每个整数可行响应均成立，包括最小值并列时；不删除任何原可行策略，也不依赖最大充电上限预处理。它们只收紧分数变量的线性松弛，从而改善全局下界；目标、价格、场景与1%门槛不变，没有用放宽精度处理失败。

## 单调充电下界与原反馈执行（2026-09-12）

适用范围仅是原方案的单段共享g/cp/rp、正电价、正场景权重、计划购电与紧急购电费用，以及无日末SOC等式的模型。固定策略校验、非默认优化选项和三段SOC模型继续精确编码；没有扩展证明到吞吐成本、负电价或终端等式。

自由策略补算保留共享日前g/cp/rp、原放电min反馈、方向、能量平衡和SOC界。仅把场景中的强制最大允许充电改成0≤c≤min(cp,g−n,(Emax−Eprev)/ηc)。求解所得场景轨迹只用于下界证书，最终策略始终交给原respond/replay执行，不能把场景充放电轨迹直接执行。

对任一相同策略和场景，记原反馈SOC为Ef，允许少充的SOC为Er。二者初态相等。若x=n−g≥0，下一步SOC是f(E)=max(Emin,E−min(rp,x)/ηd)，为单调函数；紧急购电q=max(x−min(rp,ηd(E−Emin)),0)随E不增。若x<0，Er_next≤min(Emax,Er+ηc·min(cp,−x))≤min(Emax,Ef+ηc·min(cp,−x))=Ef_next，且紧急购电均零。因此逐步归纳Ef≥Er、qf≤qr；g不变，原反馈的总费用不高于少充轨迹费用。

每个原精确解在该模型中可行；反之每个放松解均能用同一g/cp/rp转换为原反馈，且费用不增，所以两者最优费用相同。该MIP的全局下界L是原问题有效下界；原反馈独立重算的费用U与它构成(U−L)/max(|L|,1e−8)≤1%的证书。最大充电上限支配性预处理沿用上文证明。

自由充电时删除三个充电最小项选择变量的逻辑，且不再添加仅对精确充电成立的w分支约束与充满SOC约束；仍保留放电q分支与放空SOC约束。固定策略仍保留四条分支约束。两种编码还使用r+q≤max(n,0)z、c+w≤max(Gmax−n,0)(1−z)：同一方向的总量不能把各分量上界重复相加。选中可用电量分支时Eprev≤Emin+CAP/ηd；固定策略选中容量空间分支时Eprev≥Emax−ηc CAP。这些都直接由原反馈及一时段功率上限推出。自由策略中z=sum(lr)，lr为二元、z∈[0,1]，故z整数性由等式隐含，可不再单独标二元。

原始少充轨迹与原反馈可不同。输出明确分开raw_response_difference_kwh、monotone_projection_error_kwh（SOC不减与紧急不增的最大违反量）、linear_feasibility_error、integrality_error及费用不增判据。自由策略mapping_error_kwh为null，固定策略才记录精确映射误差。可靠性要求所有相关误差、整数性、费用不增、有效下界和1% gap共同通过；原反馈还通过原有物理检查。
