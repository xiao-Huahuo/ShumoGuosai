## 实算结果及合理性复核

全部52560个观测完整且连续，负荷/PV无空值或负值。23540个PV零值全部保留。净负荷可为负，表示该时段光伏超过负荷，不能当数据错误删除。

负荷1日/7日相关分别0.679223/0.985484；光伏为0.992314/0.990339。全年负荷有日、周频谱证据；全年PV周频不是局部峰，因此不能以高7日相关直接判断星期效应。初始1月历史分辨率只有约4周，PV微弱周频局部峰已如实保留，未据此擅自决定多季节模型。

重要的反预期现象：按原始2025年日期计算，星期五、六日均负荷约3263.827、3266.968 kW，星期日约5166.209 kW。其余星期约5162.540–5172.680 kW。原始日期与正确星期映射已核对；不猜测原因、不平移日期、不以通常周末模式改写数据。结果说明专节报告这一差异。

ADF原始序列拒绝单位根，但KPSS(c)原始负荷p约0.036、PV p<0.01；日差分后两者KPSS p>0.1，单独周差分后仍p<0.01。因此“差分越多越好”“周相关高就只做周差分”“ADF拒绝就已平稳”都不成立。图中季节处理后的方差仍随月份变化，后续模型须在可见历史内检验。
