## 缺陷处理

1. 生产禁止allow_limited，取消fallback。每个节点必须HighsOptimal，线性约束/真实回放/独立最坏分布原对偶验证通过，audit记录solution_source=optimal_solver和integer_variables=0。
2. 跨日残差直接用历史日j完整48h预测减对应真实路径。Q43午夜后仍用j日0:00预测，不拼j+1日自己的残差；完整路径必须在当前节点已实现。
3. 每条forced tail只保留自身prior mass，普通质量只能分到普通medoids；重采样和权重均守恒。
4. W56明确为预设，删除虚假calibration陈述。没有执行窗口、场景数或半径全年扫描。
5. 初始SOC统一Feb1=6000，Jan仅训练、储能停机；跨节点与跨日连续。独立worker硬截止30秒，任何失败不写正式日文件。日CSV/audit与原子state包含SHA和签名。
6. signature包含所有实际生产传递代码，source_manifest嵌入完整Q3来源、Q2预测文件/逐日选择哈希、附件哈希、实际价格预测数组哈希及Q2最终dispatch哈希。
7. 微小epsilon=1e-7消除充放电退化。如数值上重叠，使用保持SOC且降低净需求的代数变换，并重新检查DRO费用与LP最优值。
