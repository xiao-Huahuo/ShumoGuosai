# 问题四：波动电价下考虑价格—源荷联合不确定性的鲁棒滚动调度

> 2026-09-13 修复版 `q4_rescue_lp_v1`。建模约定：采用节点共同的储能充放电计划，执行块内固定，下一节点重新求解；正式期为2025-02-01至12-31，起点SOC=6000 kWh，与最终Q2一致。1月作为历史预测与残差训练期、储能不运行，从题设Jan1初值保持至Feb1。该策略类变更为连续LP，不宣称与旧饱和反馈MILP等价。W=56、S上限20、bootstrap B=100在计算前固定。仅最优解可以进入正式结果，旧未认证结果不作为结论。

## 7.1 问题分析

问题四在问题二、问题三的基础上进一步考虑外网电价的实时波动。附件 4 给出了 2025 年各时段的实际电价序列，但题目未进一步说明未来时段的实际电价在每日 `0:00` 或日内调整节点是否能够提前获知。考虑到实时电价在实际运行中随市场逐步实现，若直接将附件 4 中尚未发生的真实价格输入当前决策，将引入未来信息。为保证模型具有真实可执行性，本文采用严格因果的信息边界：

```math
\boxed{
\text{决策时刻之后尚未实现的真实电价不可直接参与当前决策}
}
```

即附件 4 中已经发生的电价作为历史观测使用，未来尚未发生的电价由历史信息进行预测；附件 4 对应时段的真实电价仅在该时段实际到达后用于状态更新与费用结算。该处理与问题二、问题三对真实负荷、真实光伏和光伏预报的区分保持一致。

因此，问题四相对于问题二、问题三新增的核心并不是简单地将固定电价替换为一条时变价格曲线，而是同时面对

```math
\boxed{
\text{未来电价不确定性}
+
\text{负荷—光伏不确定性}
+
\text{储能跨时段耦合}
}
```

其中，问题二中供能不足部分需按交易时刻电价的 `5` 倍紧急购电；问题三中调整购电还存在增购 `1.5` 倍价格和减购违约费用。因此，当净负荷异常偏高与实时电价异常偏高同时出现时，会形成显著放大的经济损失。基于此，本文将问题四建模为

```math
\boxed{
\text{周季节电价预测}
\rightarrow
\text{价格—净负荷联合样本外残差}
\rightarrow
\text{尾部保持场景缩减}
\rightarrow
\text{有限支持 Wasserstein 鲁棒化}
\rightarrow
\text{日前/四时点滚动调度}
}
```

其中，统计模型只负责描述未来价格和净负荷的不确定性，最终购电与储能策略仍由满足能量平衡、储能容量、充放电能力及结算规则的优化模型给出。

## 7.2 数据预处理与波动电价特征分析

### 7.2.1 数据整理与严格信息边界

附件 2 和附件 4 均包含 2025 年 365 天、每日 144 个 `10\,\mathrm{min}` 时段的数据，共

```math
365\times144=52560
```

个观测点。经检查，负荷、实际光伏功率和电价序列均不存在缺失记录。

预测阶段保留功率单位 `kW`；进入调度模型后统一按

```math
\Delta t=\frac16\,\mathrm h
```

转换为电量。定义第 `d` 日第 `t` 个时段的实际净负荷电量为

```math
n_{d,t}^{\rm real}
=
\Delta t
\left(
L_{d,t}-P_{d,t}^{PV,\rm real}
\right).
```

第 `d` 日 `0:00` 制定计划时，只允许使用此前已经实现的信息。若原始数据采用区间右端点记时，则某日 `23:50-24:00` 虽可能标记为次日 `0:00`，其所属运行区间已经完整发生，因此按原始所属日期归入历史样本。

对于问题 4-3，在

```math
k\in\{0,6,12,18\}\ {\rm h}
```

进行滚动决策时，将可用信息记为

```math
\mathcal I_{d,k},
```

其中仅包含：

- 节点 `k` 之前已经实现的价格、负荷与实际光伏；
- 当前真实储电量；
- 节点 `k` 最新发布的未来 `24\,\mathrm h` 光伏预报；
- 截至节点 `k` 可由历史信息构造的价格与净负荷预测量。

节点之后尚未实现的真实价格、真实负荷和真实光伏均不得进入当前优化。

### 7.2.2 电价周期性与趋势特征

对附件 4 全年实时电价进行统计，得到：

| 指标 | 结果 |
|---|---:|
| 最低电价 | `0.0076 元/kWh` |
| 最高电价 | `1.7936 元/kWh` |
| 全年平均电价 | `0.76620 元/kWh` |
| 日均价线性时间趋势 `R^2` | `0.00190` |
| 1 日同刻相关系数 | `0.93354` |
| 7 日同刻相关系数 | `0.98204` |
| 14 日同刻相关系数 | `0.97447` |

全年电价不存在明显单调时间趋势，而表现出显著的日内周期、周周期和季节性波动。其中

```math
\boxed{\rho_7=0.98204}
```

说明“上周同星期、同一时刻价格”已经能够提供很强的结构信息。

从平均日内曲线看，电价低谷主要位于凌晨至清晨，`05:40` 附近全年平均电价约为

```math
0.3713\ {\rm 元/kWh},
```

晚间形成明显高峰，`20:40` 附近平均电价约为

```math
1.3952\ {\rm 元/kWh}.
```

因此，附件 4 的主要变化模式可概括为

```math
\boxed{
\text{稳定周期结构}
+
\text{周际偏移}
+
\text{随机扰动}
}.
```

这意味着没有必要使用高复杂度模型重新学习已经十分稳定的周周期结构，本文采用 7 日同刻价格作为季节中心，再对剩余周际偏差进行低维残差校正。

### 7.2.3 价格与净负荷的联合风险

为剔除共同周期结构，首先构造 7 日异常量

```math
e^{p,7}_{d,t}
=
p_{d,t}-p_{d-7,t},
```

```math
e^{N,7}_{d,t}
=
n^{\rm real}_{d,t}-n^{\rm real}_{d-7,t}.
```

对 2—12 月全部时段计算得到

```math
\boxed{
\operatorname{Corr}
\left(
e^{p,7},e^{N,7}
\right)
=
0.67257
}.
```

进一步考察联合上尾，有

```math
\boxed{
P
\left(
e^{p,7}>Q_{0.9}(e^{p,7})
\mid
e^{N,7}>Q_{0.9}(e^{N,7})
\right)
=
54.20\%
}.
```

若二者近似独立，上述条件概率应接近 `10%`；实际结果明显更高，说明净负荷异常偏高时，电价同步异常偏高的概率显著增加。

考虑 `10\,\mathrm{min}` 数据具有较强时序相关性，进一步按完整日轨迹进行 block bootstrap。相关系数的 `95%` bootstrap 区间约为

```math
[0.654,\ 0.691],
```

联合上尾条件概率的 `95%` 区间约为

```math
[51.7\%,\ 56.5\%].
```

因此，价格与净负荷联合尾部并非由少量相邻时点造成，而具有较稳定的日尺度统计特征。

上述 7 日异常量仅用于判断联合建模是否必要。正式随机优化中不直接使用该异常量，而采用价格模型和净负荷模型各自严格滚动预测后得到的样本外残差，从而保证统计分析与后续决策的信息口径一致。

### 7.2.4 四时点光伏预报的信息差异

问题 4-3 沿用附件 3 在 `0:00`、`6:00`、`12:00` 和 `18:00` 发布的未来 `24\,\mathrm h` 光伏预报。

将各节点预测与附件 2 实际光伏重新对齐后，为避免完整 `24\,\mathrm h` 窗口中夜间零光伏占比不同造成评价偏差，重点考察“当前节点至下一节点”的未来 `6\,\mathrm h` committed block。计算得到：

| 发布节点 | 下一 `6 h` 光伏 MAE / kW | 说明 |
|---|---:|---|
| `0:00` | `2.78` | 主要处于夜间，不宜解释为模型异常准确 |
| `6:00` | `153.47` | 上午光伏不确定性较强 |
| `12:00` | `68.35` | 下午更新具有明显信息价值 |
| `18:00` | 约 `0` | 后续主要进入夜间 |

因此，不同预报发布时间的误差分布不能混入同一个误差池。本文针对不同 forecast origin 分别保存净负荷样本外误差

```math
e^N_{j,t|k},
\qquad
k\in\{0,6,12,18\}.
```

## 7.3 基于周季节残差与 Elastic Net 的电价预测

### 7.3.1 模型选择

由于附件 4 的 7 日同刻相关系数达到 `0.98204`，本文不直接对原始价格建立高维预测器，而先提取周季节中心

```math
\widetilde p_{d,t}=p_{d-7,t}.
```

定义周际残差

```math
r^p_{d,t}
=
p_{d,t}-p_{d-7,t}.
```

因此需要预测的只是

```math
\boxed{
\text{本周相对上周同刻价格发生的偏移}
},
```

而无需重新学习已经稳定存在的日内峰谷结构和周周期。

考虑 1 日、7 日和 14 日滞后价格之间存在较强共线性，纯 LASSO 可能在不同训练窗口下产生不稳定的变量选择；标准 LEAR 又需要为不同小时建立较多参数。为兼顾冷启动、稳定性、解释性和预测精度，本文采用共享参数的 Elastic Net 周季节残差模型。

### 7.3.2 低维因果特征

将每个 `(d,t)` 看作一条训练记录，144 个日内时段共享同一组回归参数。所有特征均要求在第 `d` 日 `0:00` 已经可获得，主要包括

```math
p_{d-1,t},
\qquad
p_{d-7,t},
\qquad
p_{d-14,t},
```

以及

```math
p_{d-7,t}-p_{d-14,t},
\qquad
p_{d-1,t}-p_{d-8,t},
```

用于描述近期周际变化。

此外加入上周目标时刻邻域价格差、前一日和前一周的日均价与波动率，并采用 Fourier 项刻画日内与星期周期：

```math
\sin\frac{2\pi t}{144},
\qquad
\cos\frac{2\pi t}{144},
```

```math
\sin\frac{4\pi t}{144},
\qquad
\cos\frac{4\pi t}{144},
```

```math
\sin\frac{2\pi w_d}{7},
\qquad
\cos\frac{2\pi w_d}{7},
```

其中 `w_d` 为星期序号。最终仅保留约 `15\sim20` 个具有明确时序含义的低维特征。

### 7.3.3 Elastic Net 残差回归

设特征向量为

```math
\mathbf z_{d,t},
```

则

```math
r^p_{d,t}
=
\beta_0
+
\boldsymbol\beta^\top\mathbf z_{d,t}
+
\varepsilon_{d,t}.
```

参数通过 Elastic Net 估计：

```math
\boxed{
\widehat{\boldsymbol\beta}
=
\arg\min_{\boldsymbol\beta}
\left\{
\sum_{d,t}
\left(
r^p_{d,t}
-
\beta_0
-
\boldsymbol\beta^\top\mathbf z_{d,t}
\right)^2
+
\lambda_{\rm en}
\left[
\gamma\|\boldsymbol\beta\|_1
+
\frac{1-\gamma}{2}
\|\boldsymbol\beta\|_2^2
\right]
\right\}
}.
```

其中 `L_1` 项抑制无效变量，`L_2` 项降低高相关滞后特征造成的系数不稳定。所有特征标准化参数仅使用决策时刻之前的历史样本估计。

1 月作为预热区间，在时间有序的历史训练—验证切分上选择 `\lambda_{\rm en}` 与 `\gamma`；进入 2 月后固定该超参数组合，并在每日 `0:00` 使用截至前一日的历史重新估计回归系数。

最终得到

```math
\boxed{
\widehat p_{d,t}
=
p_{d-7,t}
+
\widehat r^p_{d,t}
}.
```

在 `0:00` 预测当日未来价格时，不允许使用当日未来真实价格作为任何特征。

### 7.3.4 严格滚动样本外比较

在完全一致的 rolling-origin 信息边界下，对 7 日同刻基线、共享参数 Elastic Net 和严格因果 LightGBM 进行比较：

| 价格模型 | MAE / 元·kWh\(^{-1}\) | RMSE / 元·kWh\(^{-1}\) |
|---|---:|---:|
| 7 日同刻季节基线 | `0.04715` | `0.06535` |
| 严格因果 LightGBM | `0.04250` | `0.05948` |
| **共享参数 Elastic Net 残差模型** | **`0.04193`** | **`0.05623`** |

相对于 7 日同刻基线，Elastic Net 的 MAE 和 RMSE 分别下降约

```math
10.98\%,
\qquad
14.03\%.
```

因此附件 4 的主要结构可由“强周季节中心 + 少量线性残差修正”有效解释。正式模型选择仍以真实价格回放下的最终调度成本作为主要经济指标，预测误差仅作为辅助依据。

## 7.4 价格—净负荷联合样本外残差场景

### 7.4.1 严格样本外残差

第 `j` 日第 `t` 个时段的价格样本外残差定义为

```math
e^p_{j,t}
=
p^{\rm real}_{j,t}
-
\widehat p^{\rm OOS}_{j,t}.
```

净负荷误差沿用问题二已经确定的严格因果预测模型。对于问题 4-2，

```math
e^N_{j,t|0}
=
n^{\rm real}_{j,t}
-
\widehat n^{\rm OOS}_{j,t|0}.
```

对于问题 4-3，则分别针对

```math
k\in\{0,6,12,18\}
```

保存

```math
e^N_{j,t|k}
=
n^{\rm real}_{j,t}
-
\widehat n^{\rm OOS}_{j,t|k}.
```

联合轨迹必须来自同一历史日期：

```math
\boxed{
\boldsymbol\xi_{j|k}
=
\left(
\mathbf e^N_{j|k},
\mathbf e^p_j
\right)
}.
```

价格残差与净负荷残差不进行独立重排，从而保留二者的同步变化和联合上尾结构。

正式计算完成后，再直接基于 OOS 残差统计

```math
\rho_{\rm OOS}
=
\operatorname{Corr}
\left(
e^{N,\rm OOS},
e^{p,\rm OOS}
\right),
```

以及

```math
P
\left(
e^{p,\rm OOS}>Q_{0.9}
\mid
e^{N,\rm OOS}>Q_{0.9}
\right),
```

用于验证联合依赖在最终预测误差空间中是否仍然存在。

价格残差路径固定预测起点：`e^p_{j,k:k+T}=actual[j·144+k·6:j·144+k·6+T]-forecast[j,k·6:k·6+T]`。Q4-2取T=288、k=0；Q4-3取T=144、k=0/6/12/18。跨午夜后仍使用历史日j的0:00预测，绝不切换为j+1日自己的预测。完整残差窗口必须已经实现。

### 7.4.2 滚动残差池

由于全年不同季节的价格与净负荷波动幅度存在差异，正式场景构造不将 2 月以前的全部历史永久等权保留，而采用最近 `W` 日的联合 OOS 残差池：

```math
\boxed{
\mathcal H_{d,k}
=
\left\{
\boldsymbol\xi_{j|k}:
d-W\le j<d
\right\}
}.
```

为兼顾季节适应性与样本量，正式计算前预先固定 `W=56` 日。未执行56/84/112窗口比较，不作由调参得到最优窗口的陈述。历史不足56日时使用全部合格历史，且每条未来残差的整个窗口终点必须不晚于当前节点。

该处理既保留足够的日轨迹用于场景估计，又降低过早历史样本对当前季节分布的干扰。

### 7.4.3 当前日联合场景

对于问题 4-2，第 `d` 日联合场景由当前中心预测叠加同一历史日的联合残差得到：

```math
n_{d,t,j}
=
\widehat n_{d,t|0}
+
e^N_{j,t|0},
```

```math
p_{d,t,j}
=
\left[
\widehat p_{d,t}
+
e^p_{j,t}
\right]_+.
```

其中价格下截断仅用于排除残差叠加产生的不合理负值。

对于问题 4-3，在节点 `k` 之后仅构造未来部分：

```math
n_{d,t,j|k}
=
\widehat n_{d,t|k}
+
e^N_{j,t|k},
\qquad t>k,
```

```math
p_{d,t,j|k}
=
\left[
\widehat p_{d,t}
+
e^p_{j,t}
\right]_+,
\qquad t>k.
```

节点 `k` 之前的价格、净负荷和储能状态均使用当天已经实现的真实值，不再作为随机变量。

### 7.4.4 标准化联合距离

由于净负荷残差和价格残差量纲不同，定义标准化联合轨迹距离

```math
\boxed{
d_{ij}
=
\frac1T
\sum_{t=1}^{T}
\left[
\omega_N
\frac{|e^N_{i,t}-e^N_{j,t}|}{s^N_t}
+
\omega_p
\frac{|e^p_{i,t}-e^p_{j,t}|}{s^p_t}
\right]
}.
```

其中 `s^N_t` 和 `s^p_t` 仅由当时可用历史数据计算，可采用 MAD 或标准差。基准取

```math
\omega_N=\omega_p=\frac12,
```

本次正式计算固定该权重，不执行额外全年敏感性实验。

### 7.4.5 尾部保持的 k-medoids 场景缩减

随着历史轨迹增加，直接将所有联合场景送入优化器会增加计算量。为避免普通聚类删除样本较少但经济损失较大的“高净负荷 + 高价格”联合尾部，首先定义历史日 `j` 的标准化联合尾部风险分数

```math
\boxed{
R_j
=
\frac1T
\sum_{t=1}^{T}
\left[
\frac{e^N_{j,t}}{s^N_t}
\right]_+
\left[
\frac{e^p_{j,t}}{s^p_t}
\right]_+
}.
```

满足

```math
R_j>Q_{0.9}(R)
```

的历史日作为高风险轨迹强制保留；其余轨迹依据联合距离进行 k-medoids 聚类。

场景数量采用

```math
S_d
=
\min
\left(
S_{\max},
N_d^{\rm hist}
\right),
```

避免在历史不足时强行产生固定数量的聚类。

缩减后每个代表场景的经验概率不采用等权，而按其所代表的原始轨迹频数确定：

```math
\boxed{
\widehat\pi_s
=
\frac{|\mathcal C_s|}{N_d^{\rm hist}}
}.
```

普通轨迹只能分配到普通medoids；每个强制尾部单轨迹的质量严格等于其原始经验概率（条件化时为其原始核权重），不吸收普通簇质量，总概率守恒。从而避免“尾部强制保留 + 等权 + DRO”导致过度保守。

## 7.5 有限支持 Wasserstein 概率模糊集

联合历史残差能够描述经验分布，但有限历史样本仍存在分布估计误差。为降低优化结果对经验场景概率的过度依赖，在缩减后的有限联合场景集合上构造 Wasserstein 概率模糊集。

设经验分布为

```math
\widehat{\mathbb P}_{d,k}
=
\sum_{i=1}^{S}
\widehat\pi_i
\delta_{\xi_i}.
```

允许概率质量在现有联合轨迹之间转移：

```math
\boxed{
\mathcal P_{\rho_{d,k}}
=
\left\{
\mathbf q:
\exists\Gamma\ge0,\ 
\sum_j\Gamma_{ij}=\widehat\pi_i,\ 
\sum_i\Gamma_{ij}=q_j,\ 
\sum_{i,j}d_{ij}\Gamma_{ij}
\le
\rho_{d,k}
\right\}
}.
```

该模糊集只改变已有联合轨迹的概率权重，不凭空生成新的价格—净负荷轨迹；极端联合轨迹由前述尾部保持机制负责保留。

### 7.5.1 Wasserstein 半径的因果标定

在第 `d` 日、节点 `k`，仅使用 `j<d` 的可用历史日进行按日 block bootstrap，得到

```math
\widehat{\mathbb P}^{*(b)}_{d,k}.
```

取经验 Wasserstein 距离的 `95%` bootstrap 分位数作为半径：

```math
\boxed{
\rho_{d,k}
=
Q_{0.95}
\left[
W
\left(
\widehat{\mathbb P}^{*(b)}_{d,k},
\widehat{\mathbb P}_{d,k}
\right)
\right]
}.
```

该标定全过程只使用决策时刻之前的历史数据。

本次采用100次bootstrap，运输等式矩阵按场景数缓存；不执行额外半径扫描。

### 7.5.2 有限支持 DRO 对偶

设第 `j` 个联合场景下的运行成本为

```math
\Phi_j(x).
```

最坏分布期望

```math
\sup_{\mathbb P\in\mathcal P_\rho}
\mathbb E_{\mathbb P}
[\Phi(x,\xi)]
```

可转化为

```math
\boxed{
\min_{\lambda_W\ge0,\alpha_i}
\left\{
\lambda_W\rho
+
\sum_i
\widehat\pi_i\alpha_i
\right\}
},
```

并满足

```math
\alpha_i
\ge
\Phi_j(x)
-
\lambda_Wd_{ij},
\qquad
\forall i,j.
```

由此得到连续LP。实现额外引入场景成本上图变量phi_j，再添加S²个对偶耦合约束，直接一次求解；不使用constraint generation。目标另含7.6.2的微小吞吐量退化消除项。

## 7.6 问题 4-2：波动电价下的日前联合鲁棒调度

### 7.6.1 单时段经济机理

先忽略储能，仅考虑一个时段。设随机净需求为 `N`，随机实时电价为 `P`，计划购电量为 `q`，不足部分按 `5P` 紧急购电，则

```math
\min_q
\mathbb E
\left[
Pq
+
5P(N-q)_+
\right].
```

一阶条件为

```math
\mathbb E[P]
=
5\mathbb E
\left[
P\mathbf 1_{\{N>q\}}
\right],
```

即

```math
\boxed{
\frac{
\mathbb E
\left[
P\mathbf 1_{\{N\le q\}}
\right]
}{
\mathbb E[P]
}
=
0.8
}.
```

固定价格时退化为普通 `80%` 分位数；波动价格下则对应价格加权的 `80%` 分位数。因此，高净负荷与高价格同步出现会提高缺电状态的边际损失，这从理论上说明了联合场景建模的必要性。

### 7.6.2 计划结算量、节点储能计划和即时物理平衡

当前节点统一确定所有未来时段的 `g_t,c_t,r_t,E_t`，这些变量不带场景下标。当前执行块中的充放电量不能随未来场景改变。只允许计划调用 `x_{jt}`、紧急购电 `h_{jt}` 和弃电 `w_{jt}` 随当前净负荷即时平衡。

```math
0\le g_t\le \max(0,\max_j n_{jt})+CAP,\qquad 0\le c_t,r_t,\quad c_t+r_t\le CAP,
```

```math
E_t=E_{t-1}+0.9c_t-r_t/0.9,\qquad 1200\le E_t\le10800,
```

```math
0\le x_{jt}\le g_t,\qquad h_{jt},w_{jt}\ge0,
```

```math
x_{jt}+r_t+h_{jt}=n_{jt}+c_t+w_{jt},\qquad u_{jt}=g_t-x_{jt}\ge0.
```

其中 `CAP=5000/6` kWh，全部变量连续。结算按 `g_t` 付费，未调用额度 `u_{jt}` 不等于物理弃电。实际回放不取任意退化LP调用量，而按以下仅用当前值的规则确定：

```math
b_t=n_t+c_t-r_t,\quad x_t=\min(g_t,[b_t]_+),\quad
h_t=[b_t-x_t]_+,\quad w_t=[x_t-b_t]_+.
```

这是无需优化未来信息的即时平衡规则。上述正部运算仅用于回放，优化模型使用前述线性不等式。

为消除同时充放电退化，目标增加 `10^{-7}\sum_t(c_t+r_t)`。若数值解仍有重叠，令 `δ=min(c,r/(0.9²))`，变换为 `c'=c-δ,r'=r-0.9²δ`；SOC不变，净需求减少，所有非负价格场景成本不增加。审计记录移除量，并重新验证回放费用与LP原对偶最优值的一致性。这一消除不引入整数变量。

Jan1至Jan31储能不运行、SOC保持6000 kWh，Feb1正式计算从6000开始；之后SOC在日与节点间连续传递，不额外要求每日首尾SOC相同。

### 7.6.3 向下一日延伸的 continuation horizon

问题 4-2 每天仅在 `0:00` 制定一次正式计划。若优化时域只截止当天 `24:00`，模型可能由于忽略日末储电量的后续价值而非理性放空电池。为此，将优化窗口从当前 `0:00` 向后延伸 `48\,\mathrm h`：当前日 `24\,\mathrm h` 为正式决策区间，下一日 `24\,\mathrm h` 仅用于 continuation 价值评估。

记

```math
\mathcal H_d^{\rm cur}
```

为当前日 144 个时段，

```math
\mathcal H_d^{\rm cont}
```

为紧接其后的下一日 144 个时段。则：

- `\mathcal H_d^{\rm cur}` 中的 `g^{\rm plan}_{d,t}`、储能充放电计划及其执行结果为正式决策；
- `\mathcal H_d^{\rm cont}` 中引入临时购电量 `g^{\rm cont}_{d,t}` 和对应临时储能计划变量，仅用于衡量当前日末储电状态的未来经济价值；
- continuation 区间使用当时可获得的递推负荷/光伏预测、价格预测及联合残差场景；
- 下一日真正到达 `0:00` 后，重新基于最新信息求解，前一日产生的 continuation 决策不直接执行，也不写入最终结果文件。

因此，跨日延伸不是人为规定终端储电量，而是通过下一日预测运行成本内生评估

```math
E_{d,144}
```

的延续价值。

### 7.6.4 完整 continuation 成本与鲁棒目标

场景 `j` 下，当前日正式决策的成本为

```math
\boxed{
\Phi_{d,j}^{\rm cur}
=
\sum_{t\in\mathcal H_d^{\rm cur}}
p_{d,t,j}
\left(
g^{\rm plan}_{d,t}
+
5h_{d,t,j}
\right)
}.
```

注意其中正常购电费用始终按计划结算量 `g^{\rm plan}_{d,t}` 计算，而非按实际调用量 `x_{d,t,j}` 计算。

下一日 continuation 区间的预测运行成本明确写为

```math
\boxed{
\Phi_{d,j}^{\rm cont}
=
\sum_{t\in\mathcal H_d^{\rm cont}}
p_{d,t,j}
\left(
g^{\rm cont}_{d,t}
+
5h^{\rm cont}_{d,t,j}
\right)
}.
```

其中 `g^{\rm cont}_{d,t}` 及对应的
`x^{\rm cont}_{d,t,j},c^{\rm cont}_{d,t,j},r^{\rm cont}_{d,t,j},
h^{\rm cont}_{d,t,j},w^{\rm cont}_{d,t,j}`
满足与当前日相同的能量平衡、储能状态转移及节点共同储能计划约束，但均属于 provisional decision。

完整 48 h 场景成本为

```math
\boxed{
\Phi_{d,j}^{(4-2)}
=
\Phi_{d,j}^{\rm cur}
+
\Phi_{d,j}^{\rm cont}
}.
```

因此问题 4-2 求解

```math
\boxed{
\min_{\Theta_d}
\sup_{\mathbb P\in\mathcal P_{\rho_{d,0}}}
\mathbb E_{\mathbb P}
\left[
\Phi_d^{(4-2)}(\Theta_d,\xi)
\right]
}.
```

其中 `\Theta_d` 表示当前日正式决策及 continuation 临时决策的集合。求解完成后，只提交和执行 `\mathcal H_d^{\rm cur}` 中的正式计划；`\mathcal H_d^{\rm cont}` 仅用于消除日末边界效应。

## 7.7 问题 4-3：价格—源荷联合不确定性下的四时点鲁棒滚动优化

### 7.7.1 四时点信息结构

问题 4-3 在每天

```math
k\in\{0,6,12,18\}
```

四个节点重新优化。

`0:00` 根据

```math
\mathcal I_{d,0}
```

制定当天基准购电计划

```math
g^0_{d,t}.
```

到达 `6:00`、`12:00` 或 `18:00` 后，仅允许使用：

```math
\boxed{
\text{截至当前已实现的价格、负荷、光伏和储电量}
+
\text{当前节点最新光伏预报}
```

更新尚未执行部分。已执行购电与储能动作永久冻结，过去决策不得修改。

### 7.7.2 前缀状态与未来误差必须分离

不同 forecast origin 的净负荷残差只对该节点之后的未来预测有定义。因此，不能直接用

```math
e^N_{j,1:k|k}
```

描述节点 `k` 以前的历史前缀。

为保持时序一致，对每个历史日 `j`、节点 `k` 保存二元对象

```math
\boxed{
\left(
\mathbf z^{\rm prefix}_{j,k},
\mathbf e^{\rm future}_{j,k}
\right)
}.
```

其中前缀状态

```math
\mathbf z^{\rm prefix}_{j,k}
```

只由节点 `k` 之前已经实现的信息构成，可包括：

```math
\text{截至 }k\text{ 的价格残差统计},
```

```math
\text{截至 }k\text{ 的净负荷残差统计},
```

```math
\text{最近 }1{\rm h}/3{\rm h}\text{ 平均异常},
```

```math
\text{累计净负荷异常},
```

本次前缀仅使用上述7维价格/净负荷统计，不加入历史策略SOC；当前真实SOC单独作为优化初始状态。

其中历史净负荷前缀统一相对于 `0:00` 基线预测计算，从而保证每个节点都存在可比较的历史前缀。

对应的未来误差部分则使用真正由节点 `k` 预报产生的

```math
\mathbf e^{N,\rm future}_{j|k}
=
\left(
e^N_{j,t|k}
\right)_{t>k},
```

并与同一历史日的未来价格残差

```math
\mathbf e^{p,\rm future}_{j|k}
=
\left(
e^p_{j,t}
\right)_{t>k}
```

绑定。

### 7.7.3 根据已实现前缀更新未来场景概率

对当前日 `d` 在节点 `k` 已经实现的状态构造

```math
\mathbf z^{\rm obs}_{d,k}.
```

计算其与历史日 `j` 前缀的标准化距离

```math
D_{j,k}
=
d_z
\left(
\mathbf z^{\rm obs}_{d,k},
\mathbf z^{\rm prefix}_{j,k}
\right).
```

采用核权重更新历史轨迹先验概率：

```math
\boxed{
\widehat\pi_{j|k}
=
\frac{
\exp(-D_{j,k}/h_k)
}{
\sum_{\ell}
\exp(-D_{\ell,k}/h_k)
}
}.
```

带宽 `h_k` 仅根据历史前缀距离分布确定，不使用当前节点之后的真实数据。

随后取同一历史日 `j` 对应的未来联合残差

```math
\left(
\mathbf e^{N,\rm future}_{j|k},
\mathbf e^{p,\rm future}_{j|k}
\right)
```

作为后续轨迹。因此该更新近似刻画

```math
\boxed{
P
\left(
\xi_{k+1:T}
\mid
\mathbf z_{1:k}
\right)
},
```

而不是在节点更新后重新独立抽取价格误差和净负荷误差。

为防止核权重过度集中，计算有效样本量

```math
\boxed{
ESS_k
=
\frac1{
\sum_j\widehat\pi_{j|k}^2
}
}.
```

若 `ESS_k` 低于预设历史阈值，则适当增大 `h_k`，直至条件场景分布具有足够支持度。

更新后的条件经验分布再进入节点 `k` 对应的 Wasserstein 概率模糊集。

### 7.7.4 6 h committed block 与 24 h receding horizon

每个节点向未来优化 `24\,\mathrm h`，但只有当前节点到下一节点之间的 `6\,\mathrm h` 决策真正提交：

```math
[k,k+6{\rm h})
```

为 committed block。

更远时段属于 continuation，用于评估储能状态和未来调整价值；下一节点到达后，这些尚未执行的 provisional decision 重新优化。

当 `24\,\mathrm h` 预测窗口跨入次日时：

- 当前日尚未执行时段的购电量按照问题三的调整结算规则计费；
- 跨入次日的 provisional purchase 尚不存在当日 `0:00` 基准计划，因此仅按正常预测交易价格计入 continuation cost，不施加本日调整违约费用；
- 次日 `0:00` 到达后重新生成该日正式基准计划。

由此避免将本日调整规则错误延伸到次日尚未形成的计划。

### 7.7.5 调整购电结算量与实际物理调用量

记当天 `0:00` 制定的基准计划购电结算量为

```math
g^0_{d,t},
```

节点 `k` 重新优化后，对尚未执行时段形成新的有效购电结算量

```math
g^{(k)}_{d,t}.
```

对某一时段，最终实际生效的结算量记为

```math
g^{\rm eff}_{d,t}.
```

定义相对于 `0:00` 基准计划的增购量和减购量

```math
\Delta^+_{d,t}
=
\left(
g^{\rm eff}_{d,t}
-
g^0_{d,t}
\right)_+,
```

```math
\Delta^-_{d,t}
=
\left(
g^0_{d,t}
-
g^{\rm eff}_{d,t}
\right)_+.
```

对同一时段可能存在的多次滚动修订，本文以最终实际生效结算量相对于 `0:00` 基准计划统一结算，避免对同一电量重复计算调整费用。

与问题 4-2 相同，购电**结算量**与实际进入微网的**物理调用量**需要分开。对场景 `j`，记实际从有效购电额度中调用的电量为

```math

```

并满足

```math
\boxed{

\le

\le
g^{\rm eff}_{d,t}
}.
```

相应的

```math
u^{\rm eff}_{d,t,j}
=
g^{\rm eff}_{d,t}
-
x^{\rm eff}_{d,t,j}
\ge0
```

表示已经按最终计划/调整规则结算，但在该实际状态下未被物理调用的电量。

按照题目规则，若最终增购，增加部分按交易时刻电价的 `1.5` 倍支付；若最终减购，则计划与最终购电量之差承担 `50%` 的违约费用。因此场景 `j` 下，节点 `k` 之后当前日尚未执行部分的结算成本为

```math
\boxed{

=
\sum_{t\in\mathcal T_{d,k}^{\rm cur}}
\left[
p_{d,t,j}g^0_{d,t}
+
1.5p_{d,t,j}\Delta^+_{d,t}
-
0.5p_{d,t,j}\Delta^-_{d,t}
+
5p_{d,t,j}h_{d,t,j}
```

其中

```math
\mathcal T_{d,k}^{\rm cur}
```

表示节点 `k` 之后、当天 `24:00` 之前尚未执行的时段。节点 `k` 之前已经结算的费用对当前优化而言是常数，因此不再重复进入目标函数，但会计入最终真实全年费用。

需要强调，正常购电及调整费用均按
`g^0_{d,t},g^{\rm eff}_{d,t}`
等**结算量**计算；能量平衡则使用
`x^{\rm eff}_{d,t,j}`
等**物理调用量**。

### 7.7.6 节点共同储能计划与物理平衡

在节点 `k`，使用当前真实SOC重新求解7.6.2的共同储能变量 `c_t^{(k)},r_t^{(k)},E_t^{(k)}`，与购电额度 `g_t^{(k)}` 一起只提交下一6小时。当前执行块内这些变量对所有场景相同，不使用未来真实净负荷调整储能计划；下一个节点才能基于新信息重算。

并且
`x^{\rm cont},c^{\rm cont},r^{\rm cont},h^{\rm cont},w^{\rm cont},E^{\rm cont}`
满足与当前日相同的物理能量平衡、储能状态转移和节点共同储能计划约束。

节点 `k` 的完整滚动场景成本因此为

```math
\boxed{

=
\Phi_{d,k,j}^{\rm cur}
+
\Phi_{d,k,j}^{\rm cont}
}.
```

其中 continuation 部分只用于衡量当前储能状态和未来计划的延续价值。次日真正到达 `0:00` 后重新制定正式基准计划，先前的 `g^{\rm cont}` 不直接执行，也不进入最终比赛结果。

## 7.9 问题四模型特点

问题四并非简单将附件 4 的真实价格直接代入优化器，而是按照真实运行时序区分“已经实现的价格”和“尚未实现的未来价格”。附件 4 中未来真实价格只承担事后回放和费用结算作用，从而保证所有计划与调整策略均具备可执行的因果信息结构。

首先，附件 4 显著的 7 日周期支持采用

```math
\boxed{
\text{7 日季节中心}
+
\text{共享参数 Elastic Net 残差校正}
}
```

预测未来价格；

其次，价格与净负荷异常具有明显联合上尾，因此采用

```math
\boxed{
\text{同日绑定的价格—净负荷 OOS 联合残差轨迹}
}
```

刻画未来不确定性；

进一步通过滚动残差池、尾部保持 k-medoids 和有限支持 Wasserstein 概率模糊集，降低季节漂移、有限样本和极端联合状态对经验场景估计的影响；

最后，在问题 4-3 中将“已实现前缀”和“节点 `k` 的未来 forecast-origin residual”严格分离，并利用当前联合前缀对未来场景概率进行条件更新，使

```math
0{:}00,\ 6{:}00,\ 12{:}00,\ 18{:}00
```

四次决策形成严格因果的滚动闭环。

因此，问题四的整体建模思想为

```math
\boxed{
\text{严格因果价格预测}
\rightarrow
\text{价格—净负荷联合 OOS 残差}
\rightarrow
\text{尾部保持场景缩减}
\rightarrow
\text{有限支持 Wasserstein DRO}
\rightarrow
\text{节点预提交储能计划}
\rightarrow
\text{四时点滚动执行}
\rightarrow
\text{真实价格回放结算}
}.
```

整个框架始终遵循“预测模型描述未来、优化模型制定策略、购电结算量与物理调用量分离、真实数据只在实现后参与状态更新和结算”的原则，从而在保持问题二、问题三调度结构的基础上，完整刻画波动电价带来的新增决策风险。
