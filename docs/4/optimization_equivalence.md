# 第四问计算优化等价性说明

## 结算量与物理调用量

第三问快速矩阵中的总富余量为

```math
v_t=[g_t-n_t-c_t+r_t]_+.
```

第四问按方案重新拆成

```math
x_t=\min\{g_t,[n_t+c_t-r_t]_+\},\quad
u_t=g_t-x_t,\quad
w_t=[-n_t-c_t+r_t+x_t]_+.
```

逐种符号情形可直接得到 `v_t=u_t+w_t`。因此第三问矩阵的充电、放电、紧急购电和 SOC 可原样复用，真实回放再把总富余精确拆为未调用计划电量 `u` 与物理弃电 `w`。费用始终按结算量 `g` 计算，能量平衡始终按调用量 `x` 计算，两者没有混用。

## 充电上限与购电上界

在给定正电价计划结算量后，提高事前充电反馈上限只可能增加可吸收电量和后续 SOC，不增加紧急购电；因此存在最优解令 `bar_c=P_max Δt`。这与第三问已测试的单调充电等价结构一致。`g_t>max_j[n_{j,t}]_++P_maxΔt` 的额外计划电量在所有场景中都不可能被负荷或储能调用且价格非负，严格受支配，故该值是安全有限上界。

## Wasserstein 约束生成

直接对偶包含所有 `i,j` 约束。生产路径改为维护若干歧义集内概率分布 `q^m`：

```math
\theta\ge\sum_j q_j^m\Phi_j(x).
```

每轮主 MILP 给出策略与受限主问题全局下界；随后运输 LP 在完整 Wasserstein 集上求该策略的真实最坏分布并加入新切面。受限主问题的下界始终也是完整问题的有效下界，运输 LP 值始终是当前策略的有效上界。两者 gap 达标即形成完整问题证书；若分离不再违反，有限支持问题已精确闭合。小型问题中该路径与 `S²` 直接对偶最优值逐值一致。
