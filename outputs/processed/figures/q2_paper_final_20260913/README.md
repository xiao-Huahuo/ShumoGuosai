## 重要数据口径

- 图5-1：工作日指周一至周五，不涉及法定节假日调休；阴影是跨日25%–75%分位范围，不是均值置信区间。曲线使用10分钟右端点0:10—24:00，不编造缺失0:00样本。
- PV去周期使用每月×时刻均值，仅为事后结构诊断，不回流预测；不是DHR-ARMA最终创新项的白噪声检验。ACF阴影为逐点95% Bartlett参考带，不是同时置信带。负荷相关图完整保留负相关值。
- 图5-2：采用304个具备三日前瞻且真值完整的共同预测起点，每个h为43776条时段记录。误差=真实净负荷−同起点预测，单位kWh/10min。箱体为Q1—Q3、中位线及1.5×IQR范围内最远观测的箱须，全部离群点保留。
- 80%场景区间实际覆盖率约78.8%—79.2%，90%区间约85.7%—86.0%。不能写成完全校准；也没有用其他日期支持集混淆h之间比较。
- 图5-4：按题目指定四日中紧急量最大规则选2025-03-20，紧急电量53.567333kWh。Z定义为储能前净负荷正部。红柱高度是真实紧急量，淡红背景仅标识发生时段，未夸大能量；充电为正、放电为负；SOC有145点并含真实日初值。
- 图5-5原要求为全年对照，但现有三组全年数据属于旧版初值/风险机制。用户已确认改为当前模型代表日局部对照，图上明确标注“非全年”。采用此前规则选定的2025-09-17、06-01、06-02、09-28，K1/2/3共12次同机独立重求解，均达到3%证书；同一S26联合72h场景分别取144/288/432段前缀，固定各日日初SOC、概率、R和价格。没有覆盖正式结果。
- K1/2/3平均日费分别68698.881、72523.517、71555.496元，平均求解时间4.015、6.784、9.642秒。平均日末SOC分别1468.406、7830.915、7817.796kWh。24h当日费低伴随库存消耗，不能单凭该图说24h跨日经济性最优；费用也不是全年总费用。
- 附加热图逐格保留365×144原数据，未平滑。净负荷色标以0为中心；不同物理变量各自有标尺与单位。

## 文件说明

PNG可直接插入文稿，SVG用于矢量排版；index.html浏览全部图。captions.md给逐图图注，data/保存完整绘图数据及来源哈希，manifest.json记录图片尺寸/字体/SHA，verification.json记录数值和导出检查。src/是绘图与局部对照代码副本，requirements-plotting.txt是绘图依赖。

## 从缓存数据重绘

解压到独立目录，在该目录安装依赖后执行：

```sh
python -m pip install -r requirements-plotting.txt
python -m src.plots.q2_paper_final --data-dir data --output-dir 重绘输出
```

需要常见中文字体（Heiti/微软雅黑/思源黑体等）；脚本会检查字体，避免输出缺字。上述命令只重绘已保存数据，不会重新求解。完整重建原始数据与局部K计算需原项目输入，代码保留用于追溯。

本图集依照scientific-figure-making、scientific-visualization、matplotlib技能制作；未声明符合某个未指定期刊的格式标准。所有图已在完整数据范围下进行目视检查，来源与解释限制随图保留。

配色按用户最新要求调整：深海蓝—中蓝—浅蓝多强度序列为主，曲线优先用蓝色，以线型和标记辅助区分；负荷/PV热图使用蓝色连续渐变，净负荷在0处以浅色为中心、蓝灰/深蓝区分负正；暗红仅用于紧急补购和禁止信息提示。
