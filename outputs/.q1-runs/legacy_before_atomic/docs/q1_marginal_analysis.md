# Q1 边际价值强化版分析结果

假设与数值设置：沿用右端点、ZOH、母线侧电量、双单程0.9、不售电与允许弃光；Qmax按5000/6准确计算，CSV交付。活跃性与验收容差1e-6；主情景容量/功率步长1、10、100 kWh/kW，其余情景步长1；局部RHS步长±0.01 kWh。这些是数值分析设置，模型原稿和设备基准参数未改写。

无储能费用为48052.046591元，仅光伏消纳储能为41324.767400元，完整MILP为35126.948589元。两步增量节约分别为6727.279191元和6197.818811元，总计12925.098002元；它们依赖基准设置，不是唯一的光伏/套利因果分解。

连续松弛费用35126.948589290元，整数松弛间隙2.071e-16；分数模式26个，同时充放电0个。仅说明本算例的松弛紧度，不能推出MILP与LP普遍等价，也不使用松弛解替换正式调度。

固定MILP最优模式后，用母线等式 G−C+D−W=L−S+b 的右端项导数定义μ；用状态等式 Eₜ−Eₜ₋₁−ηC+D/η=h 的负导数定义λ。h表示在第t时段末额外注入内部电量，初始储量和日末目标保持不变；这与直接抬高Eₜ下限或日末目标不是同一扰动。μ、λ仅适用于所选最优模式附近，模式切换、活跃边界和对偶退化都可能改变它们。

充电倾向条件为μ<ηλ，待机区间为ηλ≤μ≤λ/η，放电倾向条件为μ>λ/η。等号表示边际无差异，允许出现非零充放电；固定模式不允许的方向不能仅凭阈值执行。本次主方案有21个时段的严格阈值倾向受固定模式限制。对144个母线需求和144个内部注入方向分别作±0.01kWh重求，其中25项为非光滑或单侧情况，保留两侧差分与不可行状态，并检验影子价格位于可行方向的差分区间内；不伪称每个点都有唯一导数。

主模型的未来电价须严格超过当前电价的1.234567901倍，忽略其他约束时才有正的外网跨期收益。等价阈值pₛ>pₜ/(ηcηd)仅是经济条件，不保证计划可执行；原本将被弃置的光伏不适用外网购电倍率。

安全储能上限基准活跃21个时段；分别增加1、10、100个单位后的单位日价值为0.655045556、0.655045556、0.655045556（yuan/(kWh day)）。活跃且放宽后费用下降，属于本算例的有效经济瓶颈。

充电功率基准活跃19个时段；分别增加1、10、100个单位后的单位日价值为0.056466667、0.056466667、0.056466667（yuan/(kW day)）。活跃且放宽后费用下降，属于本算例的有效经济瓶颈。

放电功率基准活跃0个时段；分别增加1、10、100个单位后的单位日价值为0.000000000、0.000000000、0.000000000（yuan/(kW day)）。该方向放宽的节约在容差内为零，不是本算例的有效经济瓶颈。

储能空间与功率价值的单位不同，不能直接按数值大小推导设备投资优先级；安全上限放宽是分析实验，原正式结果仍采用10800kWh与5000kW。
