# 支撑材料说明

本目录收集C题四问的现有源程序、实际输入、正式结果、模型文档和实验材料，并附AI使用报告。所有材料均以文件和目录形式保存，没有新建压缩包，也未将已有ZIP、RAR或源码归档包作为交付物放入本目录。论文正文及最终附录由作者处理；作者补充的三项外部文献见 `参考文献/`，其中两篇论文全文已保存，书籍全文尚未成功下载。

材料内容与来源逐文件列在[文件清单.csv](文件清单.csv)，运行入口与环境说明见[运行说明.md](运行说明.md)。复制文件保留原字节，SHA-256用于核对副本与来源；第一问少量源码的历史换行还原单独记录，没有覆盖现有程序。未压缩体积、文件数和实际校验结果见[校验结果.json](校验结果.json)。

## 使用说明

[运行说明.md](运行说明.md)说明入口、环境和版本选择。第三、四问应使用与正式结果对应的冻结代码，旧脚本中的本机绝对路径需要随运行位置调整。本次检查了复制字节、正式轨迹行数、源码语法和冻结源码哈希，没有重新执行全年求解。

现有源码、正式运行快照和数值验证证据均保留；第一问和第二问历史版本差异见 `源码版本核对.csv`。运行所需环境与绝对路径调整见运行说明，AI工具的历史版本信息未完整记录。内部任务历史、操作清单、计划笔记和重复目录说明已移出本提交目录；模型依据、求解证书及相关数据仍随材料保存。

依据截图要求，作者还需把支撑材料文件列表和实际使用的源程序代码放入参赛论文附录，并在论文中注明AI使用。文件清单列出本目录文件，可据最终论文引用范围整理附录；本目录不是最终论文PDF。截图中的20M限制针对压缩文件，本次按要求不压缩，尚未验证未来压缩体积。没有执行查重操作。
