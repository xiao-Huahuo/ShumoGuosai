# 支撑材料说明

本目录保留实际源程序、运行必需的数据与模型文件、五份最终Excel、实验输入和汇总，以及AI使用说明和参考文献。大量图片、重复结果、逐节点日志和非必需中间输出已移出。本目录未压缩，实际文件数和体积见[校验结果.json](校验结果.json)。

| 位置 | 内容 |
| --- | --- |
| `src/` | 四问代码、测试、绘图与实验程序、依赖清单。 |
| `docs/CUMCM2026Problems/C题/` | C题题面、附件1至4和官方结果模板。 |
| `docs/1/` 至 `docs/4/` | 程序读取的模型依据、必要运行说明和正式结果验收摘要。 |
| `docs/4/rescue_lp/frozen_source_v2/`、`frozen_source_v3/` | 第四问两种模式实际使用的源码版本。 |
| `inputs/q4/rescue_processed/` | 正式价格预测及残差缓存，避免重训导致版本差异。 |
| `outputs/final/` | `result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4-2.xlsx`、`result4-3.xlsx`。 |
| `outputs/q2/dispatch_runs/` | 第三、四问实际读取的预测与逐日选择；Q2正式准备库及必要基准数据。 |
| `outputs/q3/raw/full_priority_rescue_7h_20260912/` | 第三问冻结源码和执行参数。 |
| `outputs/q4/raw/` | 第四问实验需要的正式配置、六个基准日、冻结输入及年表来源摘要。 |
| `outputs/sensitivity_q2_q3/`、`outputs/processed/sensitivity_*` | 第二、三问实验冻结输入和各问敏感性汇总。 |
| `outputs/q2/benchmarks/` | 已完成的代表日前瞻长度比较结果。 |
| `outputs/.q1-runs/` | 第一问Excel导出需要的四份小型CSV。 |
| [AI使用报告.md](AI使用报告.md) | 人工建模与AI辅助编程、调试、运行和文献检索的分工说明。 |
| [参考文献](参考文献/README.md) | 两篇论文全文及三项文献书目信息；Finding Groups in Data未附全文。 |
| [文件清单.csv](文件清单.csv) | 每份文件的来源、用途和SHA-256。 |
| [运行说明.md](运行说明.md) | 运行入口、版本、数据准备和精简范围。 |

`outputs` 中保留的文件多数实际承担后续问题的输入作用，直接删去会导致缺少预测、选择记录或实验基准。完整年表仅用于第四问敏感性入口计算来源摘要的两处，已改用真实原件的SHA记录，六个实际基准日仍逐值保留；项目原程序和完整年表在原项目及备份中保留。

本次已实际检查第一问输入，以及第二、三、四问数据加载；没有重新执行全年求解。绘图程序仍在，已生成图片和多数绘图中间表不随本精简目录保存，需要重新计算/生成后再绘图。程序和JSON中的运行路径按运行说明使用。

第三问的限时可行结果仍按[原正式验收记录](docs/3/production_rescue/acceptance.json)说明精度。论文附录需列出材料清单和实际使用代码，论文中注明AI使用，由作者完成。是否达到最终压缩20M限制尚未测试。
